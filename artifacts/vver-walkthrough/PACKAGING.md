# Сборка релизного бандла и упаковка в установочный пакет

Приложение **«ВВЭР-1000 — 3D/VR-обход энергоблока АЭС»** настроено на полностью автономную работу без доступа к интернету и использует относительные пути (`base: './'`, `import.meta.env.BASE_URL`).

## 1. Подготовка и проверка оффлайн-ассетов

Перед сборкой убедитесь, что в каталоге `public/` присутствуют:
- `public/assembly.glb` — CAD-модель станции;
- `public/favicon.svg` — иконка приложения;
- `public/draco/` — локальные декодеры `draco_decoder.js`, `draco_decoder.wasm`, `draco_wasm_wrapper.js`.

## 2. Сборка релизного бандла

Выполните из каталога `artifacts/vver-walkthrough`:

```bash
npm run build:release
```

Команда последовательно выполняет:
1. Проверку строгих типов TypeScript (`tsc -p tsconfig.json --noEmit`).
2. Сборку Vite в каталог `dist/` с `base: './'` и разделением чанков (`vendor-react`, `vendor-three`).
3. Автоматическую верификацию `scripts/verify-release.mjs` (проверка относительных путей `./` в `dist/index.html`, наличия `dist/assembly.glb` и `dist/draco/`, отсутствия внешних CDN).

Если требуется развёртывание в конкретной подпапке веб-сервера (например, `/vver/`), задайте переменную окружения:

```bash
BASE_PATH=/vver/ npm run build
```

## 3. Требования к запуску для HTC Vive / WebXR

WebXR API (`navigator.xr`) по спецификации браузеров работает только в защищённом контексте:
- `http://localhost:<порт>` / `http://127.0.0.1:<порт>` (локальный HTTP-сервер внутри установщика/лаунчера);
- либо `https://...` при развёртывании в корпоративной сети.

**Рекомендуемый способ локального запуска с HTC Vive (SteamVR + OpenXR):**
1. Запустите **SteamVR** и убедитесь, что в настройках выбран активный OpenXR runtime (**SteamVR OpenXR**).
2. Поднимите встроенный локальный сервер на базе папки `dist/` (например, внутри лаунчера, Electron-оболочки с `http://127.0.0.1:<port>` или `npx vite preview --port 3000`).
3. Откройте приложение в **Google Chrome** или **Microsoft Edge** на `http://127.0.0.1:3000` и нажмите **«Войти в VR»**.
4. При отсутствии подключённого шлема или отказе WebXR приложение автоматически продолжает работу в **Desktop-режиме** («Прогулка 1:1» / «Обзор сборки» / «Дрон-облёт»).

## 4. Варианты упаковки в инсталлятор Windows (.exe / .msi)

### Вариант А: Electron + electron-builder (рекомендуется для автономного .exe)
1. Создайте оболочку Electron, которая поднимает локальный статический HTTP-сервер для папки `dist/` на `127.0.0.1` (для поддержки `fetch('./assembly.glb')` и WebXR) либо открывает `dist/index.html` в режиме Desktop.
2. Поместите содержимое `dist/` в ресурсы сборки (например, `extraResources` / `resources/app/dist`).
3. Соберите NSIS-установщик командой `electron-builder --win nsis`.

### Вариант Б: Портативный архив / Inno Setup с локальным сервером
1. Включите в дистрибутив каталог `dist/` и лёгкий локальный веб-сервер (например, встроенный Node.js-лаунчер или Caddy/Nginx, слушающий `http://127.0.0.1:4173`).
2. Добавьте ярлык запуска, открывающий браузер по адресу `http://127.0.0.1:4173`.
3. Соберите инсталлятор через **Inno Setup** или **NSIS**.
